# diet-chy
식품 영양 성분 분석 및 맞춤형 식단 관리 프로그램으로 단순히 영양정보를 보여주는 게 아니라 사용자가 먹은 음식을 입력하면 자동으로 분석해주는 프로그램을 만들면 됨.

🥗 Personalized Healthy Diet Management
-Green table-
건강한 식습관 형성을 위한 통합형 맞춤 건강 관리 프로그램

📌 Introduction
현대인들은 건강한 식습관의 중요성을 인식하고 있지만, 자신의 영양 상태를 파악하거나 적절한 식단을 구성하는 데 어려움을 겪는 경우가 많습니다.
또한 음식의 영양 정보를 확인하고, 개인에게 적합한 식단을 추천받으며, 친환경 식재료를 구매할 수 있는 장소를 찾기 위해 여러 애플리케이션을 이용해야 하는 불편함도 존재합니다.
이러한 문제를 해결하기 위해 개인의 신체 정보와 식습관을 바탕으로 체계적인 건강 관리를 지원하는 통합형 식단 관리 프로그램을 개발하였습니다.
본 프로그램은 식단 분석부터 맞춤형 식단 추천, 친환경 식재료 구매 장소 탐색까지 다양한 기능을 하나의 플랫폼에서 제공하는 것을 목표로 합니다.
✨ Main Features
1. 🍱 Food Nutrition Analysis
• 사용자가 섭취한 음식을 입력하면 해당 음식의 영양 정보를 분석합니다.
• 음식별 영양 정보를 확인하여 자신의 식습관을 파악할 수 있습니다.
• 일상적인 식사에서 영양 균형을 고려할 수 있도록 지원합니다.
2. 🥗 Personalized Diet Recommendation
• 사용자의 신체 정보와 건강 관리 목표를 바탕으로 맞춤형 식단을 추천합니다.
• 주메뉴뿐만 아니라 다양한 반찬과 부수적인 음식까지 고려하여 식단을 구성합니다.
• 개인의 상황에 맞는 식단을 통해 균형 잡힌 식습관 형성을 지원합니다.
3. 🌱 Eco-friendly Vegetable Store Finder
• 사용자의 주변에 위치한 친환경 채소 판매점을 탐색할 수 있습니다.
• 친환경 식재료에 대한 접근성을 높이고 지속 가능한 식생활을 실천할 수 있도록 돕습니다.
4. 📊 BMI Calculator
• 사용자의 키와 몸무게를 입력하면 BMI(체질량지수)를 계산합니다.
• 계산 결과를 통해 자신의 신체 지표를 간편하게 확인할 수 있습니다.
🎯 Project Objectives
이 프로젝트의 핵심 목표는 다음과 같습니다.
• 접근성 향상: 여러 애플리케이션에 분산된 건강 관리 기능을 하나의 플랫폼으로 통합
• 개인화: 개인의 신체 정보와 식습관을 고려한 맞춤형 식단 제공
• 영양 관리: 음식의 영양 정보를 바탕으로 자신의 식생활을 객관적으로 파악
• 친환경 식생활: 친환경 식재료 구매 장소 탐색을 통한 지속 가능한 식생활 지원
💡 Expected Effects
본 프로그램을 통해 사용자는 자신의 식습관과 영양 상태를 보다 쉽게 파악하고, 개인의 상황에 적합한 식단을 계획할 수 있습니다.
나아가 친환경 식재료에 대한 접근성을 높임으로써 개인의 건강뿐만 아니라 환경까지 고려하는 지속 가능한 식생활을 실천하는 데 기여하고자 합니다.
