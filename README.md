# THE DINING TABLE
 Personalized Nutrition & Diet Management System

식품 영양 성분 분석 및 맞춤형 식단 관리 프로그램

사용자가 섭취한 음식을 기록하면 영양 성분을 분석하고, 개인의 신체 정보와 식습관을 바탕으로 건강한 식단 관리를 지원하는 통합형 프로그램입니다.

Web Application: https://diet-chy-ycanchange.streamlit.app/





## 1. Project Introduction

현대인들은 건강한 식습관의 중요성을 인식하고 있지만, 자신의 영양 섭취 상태를 파악하고 균형 잡힌 식단을 구성하는 데 어려움을 겪는 경우가 많습니다.

기존의 영양 관리 서비스는 음식의 영양정보를 개별적으로 확인하는 데 그치는 경우가 많으며, 실제 섭취한 음식의 양과 영양소를 종합적으로 분석하거나 개인에게 적합한 식단을 구성하기 위해서는 여러 서비스를 이용해야 하는 불편함이 있습니다.

이러한 문제를 해결하기 위해 THE DINING TABLE을 개발하였습니다.

본 프로그램은 사용자가 섭취한 음식과 양을 입력하면 식품 데이터베이스를 바탕으로 열량과 주요 영양소를 분석하고, 개인의 신체 정보와 식습관을 고려한 식단 추천 및 건강 관리 기능을 제공합니다.

또한 BMI 계산과 친환경 식재료 판매 장소 탐색 기능을 함께 구성하여 개인의 건강뿐만 아니라 지속 가능한 식생활까지 고려하였습니다.

Core Objectives
- 실제 섭취한 음식을 기반으로 한 영양 성분 분석
- 개인의 신체 정보와 식습관을 고려한 맞춤형 식단 관리
- 식사 기록을 통한 영양 섭취 상태 파악
- 친환경 식재료 탐색을 통한 지속 가능한 식생활 지원



## 2. Main Features

 2.1 Food Nutrition Analysis (식품 영양 성분 분석)

사용자가 실제로 섭취한 음식을 입력하면 식품 데이터베이스를 기반으로 영양 성분을 분석하는 기능입니다.

Key Features
- 음식 이름을 검색하여 해당 식품의 영양정보 확인
- 섭취한 음식과 양을 입력하여 총영양 섭취량 계산
- 열량(kcal), 탄수화물, 단백질, 지방, 나트륨 등 주요 영양소 분석
- 음식별 영양정보와 섭취량을 바탕으로 식생활 파악
- 영양 섭취 기준과 비교하여 자신의 영양 상태 확인


입력한 음식과 섭취량에 해당하는 영양정보를 계산하여 전체 식사의 열량과 영양소를 확인할 수 있습니다.

 2.2 Personalized Diet Recommendation (맞춤형 식단 추천)

사용자의 신체 정보와 식습관을 고려하여 개인에게 적합한 식단을 추천하는 기능입니다.

Key Features
- 나이, 키, 몸무게 등 개인 신체 정보 활용
- 사용자의 식사 선호도와 음식에 대한 요구 반영
- 건강 관리 목표와 식습관을 고려한 식단 구성
- 주메뉴뿐만 아니라 반찬과 부수적인 음식까지 고려한 식단 추천
- 다양한 음식 조합을 통한 균형 잡힌 식사 구성

단순히 특정 음식만 추천하는 것이 아니라 실제 식사에 활용할 수 있도록 여러 메뉴를 조합하여 식단을 구성합니다.

 2.3 Meal Management (식단 및 영양 섭취 관리)

사용자가 입력한 식사 기록을 바탕으로 하루 동안의 영양 섭취 상태를 확인할 수 있는 기능입니다.

Key Features
- 섭취한 음식과 양 기록
- 식사별 영양 성분 확인
- 하루 동안 섭취한 총열량과 주요 영양소 확인
- 영양 섭취량과 권장 기준 비교
- 여러 날짜의 식단 기록을 통한 섭취 현황 확인

이를 통해 사용자는 자신이 어떤 음식을 얼마나 섭취했는지 파악하고, 영양소 섭취 현황을 확인하여 식습관을 개선할 수 있습니다.

 2.4 Eco-friendly Food & Smart Farm Finder (친환경 식재료 및 스마트팜 탐색)

친환경 식재료와 스마트팜 관련 정보를 탐색할 수 있는 기능입니다.

Key Features
- 사용자가 입력한 지역을 기반으로 관련 장소 탐색
- 친환경 채소 및 식재료 판매 장소 확인
- 스마트팜 관련 기업과 수직농장 탐색
- 농업 체험 및 교육 관련 장소 탐색
- 친환경 식재료에 대한 접근성 향상

건강한 식단을 구성하는 데 그치지 않고 식재료의 생산 방식과 지속 가능한 농업까지 고려할 수 있도록 구성하였습니다.

 2.5 BMI Calculator (체질량지수 계산)

사용자의 키와 몸무게를 입력하여 BMI(Body Mass Index, 체질량지수)를 계산하는 기능입니다.

Key Features
- 키와 몸무게를 이용한 BMI 자동 계산
- BMI 수치에 따른 일반적인 판정 기준 확인
- 신체 지표에 대한 이해를 돕는 정보 제공

BMI는 건강 상태를 판단하는 여러 지표 중 하나이며, 단독으로 개인의 건강 상태를 진단하는 용도로 사용하지 않습니다.



# 3. How to Use (프로그램 사용 방법)

THE DINING TABLE은 웹 브라우저에서 접속할 수 있으며, 별도의 프로그램 설치 없이 이용할 수 있습니다.

 STEP 1. Access the Program

아래 링크를 통해 프로그램에 접속합니다.

https://diet-chy-ycanchange.streamlit.app/

 STEP 2. Select a Feature

메인 화면에서 원하는 기능을 선택하여 해당 페이지로 이동합니다.

 STEP 3. Enter Personal Information

영양 성분 분석이나 식단 추천 기능을 이용할 때 필요한 정보를 입력합니다.

- 음식 이름 및 섭취량
- 나이, 키, 몸무게 등 신체 정보
- 식사 선호도 및 식단 관련 정보

 STEP 4. Check Analysis Results

입력한 정보를 바탕으로 계산된 영양 성분과 식단 추천 결과를 확인합니다.

- 음식별 열량 및 영양 성분
- 전체 섭취 열량과 주요 영양소
- 영양 섭취 기준과의 비교
- 개인 정보를 고려한 식단 추천

 STEP 5. Manage Your Diet

분석 결과를 참고하여 자신의 식습관을 파악하고, 균형 잡힌 식단을 구성하는 데 활용합니다.


# 4. Project Objectives & Expected Effects

 4.1 통합적인 건강 관리 환경 제공

영양정보 분석, 식단 추천, BMI 계산 등의 기능을 하나의 플랫폼에 통합하여 건강 관리의 접근성을 높입니다.

4.2 개인 맞춤형 영양 관리

사용자의 실제 식사 기록과 신체 정보를 활용하여 개인의 식습관을 객관적으로 파악하고 적절한 식단을 구성할 수 있도록 지원합니다.

 4.3 데이터 기반 식습관 개선

식품 영양 데이터를 활용하여 섭취한 영양소를 수치로 확인함으로써 자신의 식생활을 보다 구체적으로 이해할 수 있습니다.

 4.4 지속 가능한 식생활 실천

친환경 식재료 판매 장소와 스마트팜 관련 정보를 제공하여 건강과 환경을 함께 고려하는 식생활을 지원합니다.



# 5. Future Improvements

프로그램의 정확성과 활용성을 높이기 위해 다음과 같은 기능을 추가하고자 합니다.

- 개인별 건강 관리 목표를 반영한 식단 추천 알고리즘 개선
- 식사 기록 및 영양 섭취 데이터의 시각화
- 스마트팜 및 친환경 식재료 관련 정보의 확장



# 6. Project Vision

THE DINING TABLE은 단순히 음식의 영양정보를 확인하는 프로그램이 아닙니다.

사용자가 실제로 섭취한 음식을 데이터로 분석하고, 개인의 생활 방식에 적합한 식단을 구성할 수 있도록 지원하는 건강 관리 플랫폼입니다.

나아가 식품 데이터와 디지털 기술을 활용하여 개인의 건강과 지속 가능한 농업 및 식생활을 연결하는 것을 목표로 합니다.

**Eat Better, Live Healthier.**
